## Magyar / English felület · Hungarian / English interface

A sötét mód kapcsolója alatt választhatsz **Magyar** és **English** között. A nyelv megjegyződik. Váltáskor a beírt értékek, szűrők és nem mentett módosítások megmaradnak. A karakterek, mentett tervek és EVE-tárgyak neve változatlan.

Choose **Magyar** or **English** below the dark-mode switch in the sidebar. The language is remembered. Switching preserves inputs, filters and unsaved edits. Character, saved-plan and EVE item names remain unchanged. Menus, planning tables, blueprint settings, skills, PI, corporation pages, messages and confirmation dialogs are translated locally; no translation service is used.

## Downloads / Letöltések

- [**Mac Apple Silicon 0.9.0** — DMG](https://github.com/Bill-web-eve/eve-workshop/releases/download/v0.9.0/EVE_Muhely-0.9.0-macOS-AppleSilicon.dmg)
- [**Windows 11 x64 0.9.0** — ZIP](https://github.com/Bill-web-eve/eve-workshop/releases/download/v0.9.0/EVE_Muhely-0.9.0-Windows11-x64.zip)

**Mac:** open the DMG and copy the application to Applications. Apple Silicon only.
**Windows:** extract the entire ZIP, then run `EVE_Muhely.exe`. Keep the complete extracted folder together.

Both versions open your local browser at http://127.0.0.1:8765. No Excel, Codex or separate Python installation is needed. The packages contain no characters, plans, inventory, tokens or Client Secret; only the public EVE Client ID is preconfigured. Existing local user profiles are preserved when upgrading.

A csomagok üresek, csak a nyilvános EVE Client ID előre beállított. A meglévő helyi karakterek, tervek és beállítások frissítéskor megmaradnak.

The applications have no publisher signature; macOS has no Developer ID/notarization. **Native Windows 11 runtime execution remains unverified on this build host.** `Ellenorzes.cmd` in the Windows package checks a separate temporary profile without changing your characters or plans. SHA-256 checksum files accompany both installers.
